# Dynamic Nomogram — NVAF-Related Acute CES Outcome Prediction

Interactive web-based dynamic nomogram for predicting short-term poor outcome (mRS >2 at Day 14) in patients with acute cardioembolic stroke due to non-valvular atrial fibrillation.

## Publication

Hu J, Wang L, Chen XY, He X, Wu JC. Nomogram for predicting short-term outcome in patients with acute cardioembolic stroke due to nonvalvular atrial fibrillation. *Int J Cerebrovasc Dis* 2024; 32(10): XXX-XXX. DOI: 10.3760/cma.j.issn.1673-4165.2024.10.002

## Model

- **Variables**: NLR, Baseline NIHSS, Sex (Female)
- **N = 196** (109 female, median age 80)
- **C-statistic**: 0.820 (95% CI 0.761–0.879)
- **Internal validation**: Bootstrap × 1,000; Hosmer-Lemeshow P > 0.05

## Usage

Open `index.html` in any modern browser. The nomogram updates in real-time as you adjust the sliders.
